### 设计决策（Phase 1/2）
- **单一主角原则**：全站唯一"仪式感动效"是阅读器 3D 翻页（前进 560ms / 后退 480ms / 收尾页 600ms），其余反馈 ≤240ms。
- **弹性克制红线**：过冲 ≤4%（scale≤1.04）、最多一次回弹，防"廉价弹跳感"。
- **时长阶梯 Token**：instant 80 / fast 150 / normal 240 / entrance 320 / slow 360 / flip 560 / poll 1800ms。缓动：standard/enter/exit/bounce/bounce-soft/flip（cubic-bezier 见 tailwind.config.ts）。
- **reduced-motion 优先级**：用户显式选择 > 系统偏好（auto/on/off 三态）。

### 关键实现（Phase 3）
1. **翻页**：BookViewer 从 setCurrentPage 硬切改为纯 CSS 3D 半页翻页（perspective 1600px + rotateY 0→±180deg + 明暗扫光 + 书脊投影）。新增 isFlipping/flipFrom/flipDir 状态机 + ref 实时值解决 TTS 闭包旧 state；连点丢弃不排队 + 300ms 冷却；animationend 幂等清理 + 700ms 兜底；leaf 用旧页快照（renderPage(flipFrom)）；reduced-motion 短路直接切页。
2. **TTS 逐字高亮**：旁白从 slice 三段重建改为逐字持久 span + active 类名切换，CSS transition 真正生效（120ms 进/180ms 出）。
3. **弹窗**：TaskCard 三类弹窗统一封装 Modal，完整焦点陷阱 + ESC/遮罩/✕ 三路径 + 焦点归还 + body 滚动锁。
4. **硬切修复**：通知横幅（文档流 grid 高度过渡）、分组折叠/子项展开（grid-rows 0fr→1fr + inert）、进度条（1800ms linear 连续滑行 + sheen）、逐条 stagger 入场。
5. **动效 Token 落库**：tailwind.config.ts 新增 13 组 keyframes + 14 条 animation + duration/easing；globals.css 新增缓动/时长/状态色 CSS 变量、翻页舞台类、reduced-motion 双通道（@media + html.motion-reduced + html.motion-full）。
6. **减少动效开关**：Header 三态 switch（auto/on/off）+ localStorage['pb-motion-reduced'] 持久化 + matchMedia change 监听。
7. **状态色统一**：6 组状态色（waiting/running/paused/completed/failed/cancelled）全部改用 var(--status-*) 静态字面量映射（Tailwind JIT 可扫描），TaskCard/TaskQueue/TaskStatsCards 口径对齐。
