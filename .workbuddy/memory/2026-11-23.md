## 本轮最大的坑：`var()` + 透明度修饰符**静默不生成 CSS**

```css
bg-[var(--text-ink)]/[.06]   →  无任何规则输出（不报错、不告警、DevTools 类名还在）
bg-ink/[.06]                 →  background-color: rgb(74 44 32 / .06)   ✅
bg-[var(--info-soft)]        →  background-color: var(--info-soft)      ✅（不带修饰符正常）
```
根因：`withAlphaVariable` 对 `parseColor('var(--x)')` 返回 null → `return defaultValue` 跳过规则。
全站踩了 **23 行 / 32 处**，后果：内容选择器未选中芯片底色+边框双失效（可点格子变裸文字）、骨架屏塌成空白白卡、次级按钮失按钮感。

**验收门禁（必须为 0）**：
```bash
grep -rn "var(--[a-zA-Z-]*)\]/" --include=*.tsx app components lib | wc -l
```

**取值口径**（已写进 `tailwind.config.ts` 注释）：不需要透明度 → `text-[var(--text-ink)]`；需要透明度 → 必须别名 `bg-ink/[.06]`。

## 触控热区 `.hit-44` / `.hit-40` 的三条硬约束

`app/globals.css:147+`，`@media (pointer: coarse), (any-pointer: coarse)`（**并集**：iPad 接妙控键盘时主指针变 fine，只写 `pointer: coarse` 会让热区整体消失）

```css
:where(.hit-44) { position: relative; }   /* :where 降特异性，不顶掉 .absolute */
.hit-44::after { left/top:50%; translate(-50%,-50%); width/height: max(100%, 44px); }
```
1. **间距**：每侧外扩 `(44−w)/2`，相邻需 `gap ≥ 44 − w`（24px→20 / 28px→16 / 32px→12）
2. **宽矮/窄高件禁用**（如 `h-7 px-2` 的 70×28 重试按钮、10×10 页码点）—— 等比撑到 44×44 会纵向越界压相邻行。改用 `min-h-11` 撑本体
3. **祖先 `overflow-hidden`/`overflow-x-auto` 会裁掉 `::after`**，热区静默回落

调试开关：`document.documentElement.classList.add('debug-hit')` → 所有热区画成半透明洋红块。

## 实测抓到并修掉的 4 个真实缺陷

1. **`text-muted` 压在彩底上不达 AA**：`TaskStatsCards.tsx` 标签 10.5px，failed-soft **3.96** / running-soft 3.97 / completed-soft 4.41 → 改 `--text-body`（6.0–6.3）
2. **宽矮件误用 `hit-44`**：`ContentSelector.tsx:689`「☑ 全选可用」70×18 → 纵向各溢 13px 压进芯片和输入框，2 对热区重叠 → 改 `min-h-11`
3. **耗时显示 `29689236m 39s` + 标题被挤成「胸...」**：`TaskCard` 把 `Date.now()`（ms）减 `startTime`（秒）。`task-db.ts` 写入侧一直是 `nowSeconds()`，但库里有历史毫秒 `endTime`。加 `toMs()` 归一（`<1e11` 视为秒），两处调用点都改，修复后显示 `4m 47s` / `3m 55s`，标题恢复完整
4. **跨页缺书脊阴影**：`.spine-shadow` 类被删但 `BookViewer.tsx:876` 仍引用 → 补回，用**中心对称渐变**（`0 → .055 → .115 → .055 → 0`，48px 居中），不是 `90deg` 单侧硬边

## 已知取舍（写进交付说明，不算 bug）

- **非 iOS 导出 PDF 后 blob 留到下次导出或离开页面**（10–30MB）。用「确定时机回收」换「不猜时长」
- **导出后立即点返回**，卸载 cleanup 同步 revoke，极小概率得到不完整文件。这是"卸载必须同步清理"的固有代价
  - 准确表述应为「两跳异步 → ≥ T0 + 1000ms」，不要写成「必然几百毫秒」（Firefox 的「总是询问保存位置」会让实际余量更大）
- **下拉刷新全站禁用**（`html, body { overscroll-behavior-y: none }`），换取"误触下拉丢失 8 个已选成语"这条数据丢失路径
- **桌面首帧闪一下单页布局**：`isWide` 初始 false 避免 hydration mismatch，改「挂载后才渲染」会牺牲 LCP
- **移动端不渲染 3D 翻页**（视觉上 slide 与 leaf 都是"旧页整体离开"，语言一致）
- **Hero 插图 `<640` 不渲染**（`hidden sm:block`），省 160px 首屏高度
- **移动端 iOS 橡皮筋残留**：`overscroll-contain` 已截断滚动链，剩余是 body 级回弹，纯视觉
